Overrule

An on-chain appeal court for content-moderation decisions

not set wallet: not connected

1. Publish a rulebook

The rulebook is written on-chain once and never changes. Every later decision cites rule ids from it, so the standard an appeal is judged against cannot be edited after the fact.

2. Issue a decision

A platform action against a user, citing rules from a rulebook the same wallet published. The content URL is what validators will re-read during an appeal.

Appeal a decision

Only the wallet named as the subject can appeal, and only once. The appeal argument and any evidence URLs are stored on-chain and shown to the validators.

Adjudicate an appealed decision

Anyone may trigger adjudication once an appeal exists. Validators re-read the frozen rulebook and the live content and classify each cited rule. The outcome is derived in code, so the model never picks it.

Platform transparency

Every adjudicated appeal is counted against the platform that issued the decision. An overturn rate is the number a user cannot get from the platform today.
